## 확정된 제품 방향

- 사용자의 주목적은 수업자료 제작 도구이고 CL 학습자료는 그 다음입니다.
- AI가 필요 없는 도구는 글자 꾸미기와 수식 입력입니다.
- AI가 필요한 도구는 수식 변환과 CL 코드 해석입니다.
- 두 AI 도구는 한 번 저장한 동일한 Gemini 설정을 사용합니다.
- 각 사용자가 Google AI Studio에서 개인 키를 발급받아 쓰는 것이 기본입니다.
- 운영자 공유 키와 공유 암호는 연수 시연·초기 체험용입니다.
- 서울대 별도 API와 OpenAI·Claude 제공자는 현재 제품 범위에 추가하지 않습니다.

## 최근 완료된 작업

- 개인 Gemini 키 사용을 새 사용자 기본값으로 변경했습니다.
- README에서 실제 암호처럼 오인될 수 있는 예시를 제거했습니다.
- 이전 다른 제공자 키가 Gemini 키로 잘못 이관되는 경로를 차단했습니다.
- CL 해석기의 한국어 오류 표시, 숨은 이미지 전송, MIME·2.5MB 제한을 수정했습니다.
- 서버 중계에 운영 출처 제한, 상수 시간 암호 비교, 반복 실패 제한을 추가했습니다.
- 사용되지 않는 구형 `api/convert.js`는 저장소에서 제거했고 로컬에서는 휴지통으로 옮겼습니다.
- 메인 그래프와 예시 코드를 일치시켰고 포스트잇 간격·모션·버튼 대비를 개선했습니다.
- 이용 안내는 자체 콘텐츠의 권리를 보유하되 출처를 밝힌 교육 목적의 비상업적 이용을 허용하는 것으로 정리했습니다.
- Gemini API 키 발급 안내 페이지와 개인정보를 가린 보조 스크린샷 5장을 추가했습니다.
- 설정 화면과 수식 변환기의 키 도움말을 모두 내부 안내 페이지로 연결했습니다.

## 다음 작업

가장 가까운 후속 작업은 **배포본에서 Gemini 안내 동선과 실제 개인 키 호출을 확인하는 것**입니다.

- `settings.html`과 수식 변환기 도움말에서 `gemini-key.html`로 이동하는지 확인합니다.
- 안내 페이지에서 공식 Google AI Studio가 새 탭으로 열리는지 확인합니다.
- 실제로 새 키를 만든 직후의 복사 화면과 왼쪽 아래 `Get API key` 버튼 동작은 아직 확인하지 못했습니다.
- 유효한 개인 키로 수식 변환과 CL 코드 해석이 모두 작동하는지 확인합니다.

## 알려진 제한과 확인할 사항

- `api/ai.js`의 메모리 기반 실패 제한은 서버리스 인스턴스 전체를 아우르는 영구 제한이 아니라 보조 방어입니다.
- 실제 Gemini 호출은 유효한 개인 키 또는 운영 공유 암호로 다시 확인해야 합니다.
- `GEMINI_API_KEYS`에 같은 Google Cloud 프로젝트의 키를 여러 개 넣어도 프로젝트 단위 할당량은 늘어나지 않습니다.
- Vercel의 `SHARE_PASSWORD`, Gemini 키와 모델 값은 저장소에서 확인할 수 없습니다.
- README나 과거 Git 기록에 있었던 암호 예시는 이미 폐기된 것으로 취급하고 재사용하지 않습니다.
