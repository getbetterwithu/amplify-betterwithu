개인정보 및 AI 데이터 처리 안내

시행일: 2026년 10월 18일

BetterWithU의 Amplify 교사 도구는 회원가입을 받지 않으며, 입력 코드·업로드 이미지·AI 답변을 별도의 사용자 데이터베이스에 저장하지 않습니다.

1. Gemini로 전송되는 정보

CL 코드 해석기와 수식 변환기를 실행하면 사용자가 입력한 코드 또는 이미지가 Google Gemini API로 전송됩니다. ‘내 API 키’를 사용하면 브라우저에서 Gemini로 직접 전송되고, ‘공유 암호’를 사용하면 BetterWithU의 Vercel 중계 API를 거쳐 Gemini로 전송됩니다. 중계 API는 입력과 답변을 데이터베이스에 저장하지 않지만, Vercel과 Google은 보안 및 서비스 제공에 필요한 기술 기록을 처리할 수 있습니다.

무료 Gemini API에서는 입력과 출력이 Google 제품 개선에 사용되거나 사람 검토자가 확인할 수 있습니다. 개인정보·민감정보·기밀정보를 입력하지 마세요.

2. API 키와 공유 암호

사용자가 입력한 개인 API 키와 공유 암호는 현재 브라우저의 localStorage에 저장됩니다. 개인 API 키는 운영자 서버로 보내지 않습니다. 운영자가 제공하는 공유용 API 키는 Vercel 환경변수에만 저장되며 페이지 소스나 브라우저로 전달되지 않습니다.

저장된 설정은 AI 사용 설정의 ‘설정 지우기’ 또는 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다. 공용·공유 컴퓨터에서는 개인 API 키를 저장하지 마세요.

3. 업로드 금지 정보

  • 학생 이름, 학번, 이메일, 얼굴 및 연락처
  • 건강·상담·성적 등 민감한 정보
  • 공개 권한이 없는 문서나 기밀자료

4. 접속 기록

이 사이트는 자체 회원 분석이나 광고 추적 도구를 사용하지 않습니다. 다만 도메인·호스팅·배포 사업자가 보안과 서비스 제공을 위해 IP 주소, 접속 시각, 브라우저 정보 등의 기술 기록을 처리할 수 있습니다.

5. 이용 대상

Gemini API가 연결된 기능은 만 18세 이상의 교사와 성인 교육자를 위한 기능입니다. 학생이 직접 사용하도록 제공하지 않습니다.
