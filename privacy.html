개인정보 및 AI 데이터 처리 안내

시행일: 2026년 10월 18일

BetterWithU의 Amplify 교사 도구는 회원가입을 받지 않으며, 운영자가 사용자의 API 키·입력 코드·업로드 이미지·AI 답변을 별도로 수집하거나 저장하지 않습니다.

1. Gemini로 전송되는 정보

CL 코드 해석기와 일부 AI 도구를 실행하면 사용자가 입력한 코드, 이미지, 해석 지침이 사용자의 브라우저에서 Google Gemini API로 직접 전송됩니다. 해당 정보는 Google의 약관과 개인정보처리방침에 따라 처리됩니다.

무료 Gemini API에서는 입력과 출력이 Google 제품 개선에 사용되거나 사람 검토자가 확인할 수 있습니다. 개인정보·민감정보·기밀정보를 입력하지 마세요.

2. API 키

API 키는 운영자 서버로 전송하거나 저장하지 않습니다. 기본적으로 현재 브라우저에서만 사용하며, 사용자가 ‘이 기기에 API 키 기억하기’를 선택하면 해당 브라우저의 localStorage에 저장됩니다.

저장된 키는 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다. 공용·공유 컴퓨터에서는 저장 기능을 사용하지 마세요.

3. 업로드 금지 정보

  • 학생 이름, 학번, 이메일, 얼굴 및 연락처
  • 건강·상담·성적 등 민감한 정보
  • 공개 권한이 없는 문서나 기밀자료

4. 접속 기록

이 사이트는 자체 회원 분석이나 광고 추적 도구를 사용하지 않습니다. 다만 도메인·호스팅·배포 사업자가 보안과 서비스 제공을 위해 IP 주소, 접속 시각, 브라우저 정보 등의 기술 기록을 처리할 수 있습니다.

5. 이용 대상

Gemini API가 연결된 기능은 만 18세 이상의 교사와 성인 교육자를 위한 기능입니다. 학생이 직접 사용하도록 제공하지 않습니다.

6. 문의 및 변경

문의는 GitHub Issues를 이용해 주세요. 안내 내용이 변경되면 이 페이지의 시행일을 갱신합니다.
