ChatGPT에 CL 해석 스킬 설치하기

ChatGPT의 스킬 메뉴에 CL 해석 스킬을 올려 두면, CL 코드를 붙여넣거나 캡처를 올릴 때 ChatGPT가 지식 파일을 참고해 줄별로 풀이합니다. 유료 계정(Plus)의 웹에서 설치되는 것을 확인했습니다.

두 가지 방법 중 하나만 하면 됩니다

  1. 컴퓨터에서 업로드 — 내려받은 zip을 그대로 올립니다. 유료 계정에서 가장 간단합니다. (추천)
  2. Codex로 설치 — VS Code나 터미널에서 Codex를 쓰신다면 저장소 주소로 설치합니다. ② 문장 하나로 설치를 보세요.

시작하기 전에

  • 이 zip은 유료 계정(Plus)의 ChatGPT 웹에서 올려 등록되는 것을 확인했습니다(2026-11-01). 다만 메뉴와 정책은 수시로 바뀔 수 있고, 올린 뒤 답이 얼마나 정확한지는 따로 확인하지 못했습니다. 되지 않으면 아래 '잘 안 될 때'를 보세요.
  • 메뉴 이름과 화면은 OpenAI가 바꿀 수 있습니다.
  • 웹 브라우저에서 해 보세요. 확인했을 때 ChatGPT 앱(데스크톱)에는 스킬 zip 업로드 메뉴가 보이지 않았고, 같은 계정의 웹(chatgpt.com/skills)에서는 업로드와 등록이 됐습니다. 앱도 버전에 따라 달라질 수 있습니다.
  • 무료 계정에서는 스킬 메뉴가 열리지 않을 수 있습니다(확인했을 때는 "이 계정에서는 스킬을 사용할 수 없습니다"라고 나왔습니다). 이 확인은 유료 계정에서 했고 요금제 정책은 바뀔 수 있습니다. 무료라면 Claude나 Gemini를 쓰는 편이 낫습니다.
  • ChatGPT의 GPT 만들기는 종료되었거나 종료될 예정으로 안내되고 있습니다(확인했을 때 화면에 "이제는 GPT를 만들 수 없습니다", "GPT는 12월 11일에 종료됩니다"라고 나왔습니다). 그래서 이 안내는 스킬 업로드와 Codex 설치만 다룹니다.
  • 업로드 창은 "타사 스킬은 위험성이 더 높으며 데이터에 액세스하려 할 수 있으니 신뢰할 수 있는 소스의 스킬만 업로드하고 사용 전에 검토하라"고 안내합니다. 이 스킬의 파일은 GitHub ↗에서 내용을 볼 수 있고, 지침과 지식 문서(.md)만 들어 있고 실행 파일은 없습니다.

0스킬 메뉴 열기

  1. ChatGPT 스킬 화면을 엽니다.
    ChatGPT 스킬 열기 ↗ 로그인 화면이 나오면 로그인하세요. 이 주소로 열리지 않으면 ChatGPT 왼쪽 메뉴에서 플러그인이나 스킬을 찾으세요.
  2. 위쪽 탭이 플러그인 · 스킬이고 스킬이 선택되어 있는지 확인합니다.
  3. 오른쪽 위의 추가 버튼을 누르면 채팅으로 만들기 · 편집기로 생성 · 컴퓨터에서 업로드 세 가지가 보입니다(그림 1). 이 안내에서는 컴퓨터에서 업로드를 씁니다.

1컴퓨터에서 업로드 추천

Gemini와 달리 zip을 풀지 않고 그대로 올립니다. 업로드 창이 .zip, .skill, SKILL.md를 받는다고 안내합니다.

  1. 스킬 zip을 내려받습니다. 압축은 풀지 않습니다.
    스킬 zip 내려받기
  2. 추가 → 컴퓨터에서 업로드를 누릅니다(그림 1).
  3. '스킬 업로드' 창에 zip 파일을 끌어다 놓거나, 창을 눌러 파일을 고릅니다(그림 2). 파일당 최대 크기는 25MB이고, 이 zip은 약 126KB입니다.
  4. '설치됨' 목록에 cl-interpreter가 보이면 끝입니다. 아래 시험으로 확인하세요.

업로드가 거절되거나 목록에 보이지 않거나, 올린 뒤 CL을 모르는 것처럼 답하면 아래 시험과 '잘 안 될 때'를 보세요.

✓잘 설치됐는지 확인하고 시험하기

  1. 먼저 등록됐는지 확인합니다. '설치됨' 목록에 cl-interpreter가 보여야 합니다.
  2. 새 채팅을 열고 아래를 보냅니다. 
    cl-interpreter 스킬을 사용해서 아래 Computation Layer 코드를 줄별로 풀이해 줘.

컴포넌트: input1
hidden: btn1.pressCount > 2
correct: this.numericValue > 9.99 and this.numericValue < 10.01
  3. 이렇게 나오면 성공입니다. 붙여넣은 텍스트의 코드 조각(hidden: btn1.pressCount > 2 등)을 인용하며 줄별로 풀이하고, 문장 끝에 공식 문서·코드 추론·추가검증필요 같은 출처 표시가 붙습니다.
  4. 실제 수업 코드는 캡처로 올리는 것이 기본입니다. 코드를 올리는 방법을 보세요.

잘 안 될 때

스킬 메뉴나 추가 버튼이 없습니다
무료 계정에서는 스킬 메뉴가 열리지 않을 수 있습니다. 이 스킬은 Claude나 Gemini에서 설치하거나 유료 계정에서 써 보세요. 학교·회사 계정이면 관리자가 업로드를 꺼 두었을 수 있습니다. 앱이 아니라 웹 브라우저로 열었는지도 확인해 보세요.
업로드가 거절됩니다
zip의 압축을 풀지 않은 상태인지 확인하세요. "SKILL.md가 없다"는 오류는 zip 안에 파일이 바로 들어 있을 때 나옵니다. 이 zip은 cl-interpreter 폴더째 압축되어 있습니다. 그래도 안 되면 Claude나 Gemini에서 설치해 보세요.
올렸는데 CL을 모르는 것처럼 답합니다
스킬이 켜져 있는지 확인하고, 요청 첫머리에 "cl-interpreter 스킬을 사용해서"라고 이름을 말해 보세요.
답이 "자료에 없습니다"인데 파일에는 있는 것 같습니다
지식 파일이 커서 일부만 읽힐 수 있습니다. 질문에 컴포넌트 이름과 sink 이름을 함께 적어 보세요.
채팅에 GitHub 주소를 알려 주고 "설치해 줘"라고 하면 안 되나요?
확인했을 때 ChatGPT 웹 채팅은 "외부 GitHub의 스킬을 ChatGPT의 스킬 목록에 직접 등록하는 기능은 없다"고 답하고 설치하지 않았습니다. 앱의 Work에서도 저장소를 zip으로 압축해 줄 뿐 스킬로 설치하지는 않았고, 이미 종료된 "GPT 만들기 → 지식에 올리기" 방법을 안내했습니다. 이런 안내는 최신이 아닐 수 있으니 위의 zip 업로드를 쓰세요. 주소로 설치하는 방법은 VS Code나 터미널에서 쓰는 AI용입니다(② 문장 하나로 설치).
