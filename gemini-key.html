Gemini API 키 발급 안내

Google AI Studio에서 Gemini API 키를 만들고 BetterWithU에 등록하는 방법을 안내합니다.

API 키 등록 순서

  1. Google AI Studio에서 API 키 메뉴를 엽니다.
  2. 새 키 만들기 창에서 프로젝트를 고르고 키를 만듭니다.
  3. 키를 복사해 AI 사용 설정의 내 API 키 사용에 붙여넣고 저장합니다.

시작하기 전에

  • 이 도구는 만 18세 이상 교사·성인 교육자용입니다. 본인의 Google 계정으로 진행하세요.
  • API 키는 비밀번호와 같습니다. 다른 사람에게 보내거나 문서, 메신저, 화면 캡처에 남기지 마세요.
  • 무료 등급을 사용하면 입력한 내용이 Google 제품 개선에 쓰일 수 있습니다. 학생 이름·얼굴·이메일 같은 개인정보는 넣지 마세요. 자세한 내용은 개인정보 및 AI 데이터 처리 안내에서 확인할 수 있습니다.

1API 키 메뉴 찾기

  1. Google AI Studio를 엽니다.
    Google AI Studio 열기 ↗ 로그인 화면이 나오면 사용할 Google 계정으로 로그인하세요.
  2. 왼쪽 메뉴에서 'API 키'를 누릅니다(그림 1의 ①). 메뉴가 없으면 왼쪽 아래의 열쇠 모양 Get API key 버튼(그림 1의 ②)을 누르세요. 영문 화면에서는 'API keys'로 표시됩니다.
  3. 오른쪽 위의 'API 키 만들기' 버튼을 누릅니다(그림 1의 ③).

2프로젝트를 고르고 키 만들기

  1. 키 이름을 확인합니다(그림 2의 ①). 기본 이름을 그대로 두거나 알아보기 쉬운 이름으로 바꿉니다.
  2. 사용할 프로젝트를 고릅니다(그림 2의 ②). 선택된 프로젝트가 있다면 그대로 사용해도 됩니다. 프로젝트가 없으면 '프로젝트 만들기'를 선택하세요.
  3. '키 만들기' 버튼을 누릅니다(그림 3의 ③).
  4. 키 오른쪽의 복사 아이콘을 누릅니다(그림 4의 ①). 키를 만든 직후 전체 키가 표시되면 그 화면에서 복사해도 됩니다. 복사한 키는 다음 단계에서 붙여넣을 때까지 다른 곳에 붙여넣지 마세요.

3BetterWithU에 키 입력하기

  1. AI 사용 설정을 엽니다.
    AI 사용 설정 열기
  2. '내 API 키 사용 · 권장' 탭을 선택합니다(그림 5의 ①).
  3. '본인의 Gemini API 키' 칸에 복사한 키를 붙여넣습니다(그림 5의 ②). Windows는 Ctrl + V, 맥은 ⌘ + V입니다. 입력한 글자는 점으로 가려집니다.
  4. 'Gemini 모델'은 기본값 그대로 둡니다.
  5. '설정 저장'을 누릅니다(그림 5의 ③). 저장 완료 메시지가 표시되면 설정이 끝납니다.

잘 안 될 때

'해석하지 못했습니다: API key not valid'가 나옵니다
키가 일부만 복사되었거나 다른 글자가 섞였을 수 있습니다. AI Studio의 'API 키' 목록에서 다시 복사해 붙여넣고 저장해 보세요.
키를 다른 사람에게 보여 주었거나 화면에 남겼습니다
AI Studio에서 노출된 키를 폐기하고 새 키를 만든 뒤 다시 저장하세요.
공용 컴퓨터를 썼습니다
키는 이 브라우저의 로컬 저장소에 보관됩니다. 사용을 마치면 AI 사용 설정에서 설정 지우기를 누르세요.
화면이 그림과 다릅니다
Google 화면은 바뀔 수 있습니다. 메뉴 이름은 'API 키'(영어로는 'API keys')를 찾으면 됩니다. 공식 설명은 Gemini API 키 공식 안내 ↗에서 볼 수 있습니다.
