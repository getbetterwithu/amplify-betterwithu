Amplify 수식 스킬 설치 안내

내가 쓰는 AI가 Amplify 수식 규칙을 미리 알게 하는 파일입니다. 교과서 수식을 Amplify용으로 옮기거나, 쓴 수식이 Amplify에서 그려질지 검수할 때 씁니다. Claude, ChatGPT, Gemini 중 하나만 성공해도 충분합니다.

어느 방법이 나에게 맞나요?

  1. 먼저 체험해 보고 싶다 → AI 수식 변환 · 웹에서 먼저 해보기에서 교과서 사진을 바꿔 보고, 마음에 들면 아래 방법으로 내 AI에 설치하세요.
  2. AI를 대화창으로만 써 봤다 → 아래 ① 처음이라면. 코딩 지식 없이 화면만 따라 하면 됩니다.
  3. Claude Code, Codex, Gemini CLI 같은 코딩 에이전트를 쓴다 → ② 경험자. 에이전트에게 설치를 시키면 됩니다.
  4. 설치가 막히거나 한 번만 쓰고 싶다 → ③ 설치 없이 붙여넣기. 가장 확실합니다.

2026-10-26에 업로드와 시험을 마친 방법입니다.

Gemini 안내 열기

세 가지 모두 업로드 → 수동(복사해 붙여넣기) → AI로 만들기 순서로 안내합니다. 업로드가 안 되면 수동으로 하면 됩니다.

②바이브코딩을 해 보셨다면 — 코딩 에이전트로 설치

Claude Code, Codex, Gemini CLI처럼 터미널에서 파일을 만들고 명령을 실행하는 에이전트가 이미 있다면, GitHub 주소를 주고 설치를 시키는 것이 가장 쉽습니다.

  1. 아래 문장을 복사해 에이전트에 붙여넣습니다. 
    이 GitHub 저장소의 skill/amplify-math 폴더를 내 스킬 폴더에 설치해 줘: https://github.com/getbetterwithu/amplify-betterwithu/tree/main/skill/amplify-math
    에이전트가 폴더를 받아 자기 스킬 폴더에 넣습니다. 설치 뒤 에이전트를 다시 시작하라고 하면 따르세요.
  2. 직접 명령으로 설치하려면 아래를 쓰세요. 각 도구 공식 문서 기준이며 제가 직접 실행해 시험하지는 못했습니다.

    Codex CLI — Codex 안에서 입력하고, 설치 뒤 다시 시작합니다.

    $skill-installer install https://github.com/getbetterwithu/amplify-betterwithu/tree/main/skill/amplify-math

    Gemini CLI — 터미널에서 입력하고, 설치 뒤 Gemini 안에서 /skills list로 확인합니다.

    gemini skills install https://github.com/getbetterwithu/amplify-betterwithu.git --path skill/amplify-math

    Claude Code — zip을 풀어 amplify-math 폴더를 내 스킬 폴더(~/.claude/skills/)에 넣습니다.

  3. 설치한 스킬은 에이전트의 권한으로 실행됩니다. 이 스킬은 규칙 문서와 지침만 들어 있고 내용은 GitHub ↗에서 볼 수 있습니다.

③설치 없이 붙여넣기 (가장 확실한 방법)

스킬을 만들지 않고 새 대화 첫 메시지에 규칙을 붙여넣어, 그 대화에서만 쓰는 방법입니다. 어떤 AI에서도 됩니다.

  1. 아래 버튼을 눌러 지침문과 규칙을 한 번에 복사합니다.
  2. 사용하는 AI의 새 대화 입력창에 붙여넣고 보냅니다.
  3. 이어서 "이 문장을 Amplify 수식으로 바꿔 줘: …"처럼 요청합니다. 새 대화를 열 때마다 다시 붙여넣어야 합니다.
