Amplify 수식 스킬 설치 안내

내가 쓰는 AI가 Amplify 수식 규칙을 미리 알게 하는 파일입니다. 교과서 수식을 Amplify용으로 옮기거나, 쓴 수식이 Amplify에서 그려질지 검수할 때 씁니다. Claude, ChatGPT, Gemini 중 하나만 성공해도 충분합니다.

어느 방법이 나에게 맞나요?

  1. 먼저 체험해 보고 싶다 → AI 수식 변환 · 웹에서 먼저 해보기에서 교과서 사진을 바꿔 보고, 마음에 들면 아래 방법으로 내 AI에 설치하세요.
  2. AI를 대화창으로만 써 봤다 → 아래 ① 처음이라면. 코딩 지식 없이 화면만 따라 하면 됩니다.
  3. VS Code나 터미널에서 Claude Code, Codex, Antigravity 같은 AI를 쓴다 → ② 문장 하나로 설치. 주소를 알려 주고 설치를 시키면 됩니다.
  4. 설치가 막히거나 한 번만 쓰고 싶다 → ③ 설치 없이 붙여넣기. 가장 확실합니다.

①처음이라면 — 웹·앱에서 설치

이미 계정이 있는 AI 하나를 고르세요. 화면 그림과 복사 버튼이 들어 있는 안내로 이어집니다.

Claude

zip을 풀지 않고 그대로 올립니다.

무료 플랜 화면에서도 Skills 메뉴가 열렸습니다.

Claude 안내 열기

ChatGPT

zip을 풀지 않고 그대로 올립니다.

무료 계정에서는 스킬 메뉴가 열리지 않을 수 있습니다. 그럴 때는 아래 ③ 붙여넣기를 쓰세요.

ChatGPT 안내 열기

Gemini

zip을 풀어 폴더째 올립니다.

스킬 메뉴에 폴더를 올립니다.

Gemini 안내 열기

세 가지 모두 업로드 → 수동(복사해 붙여넣기) → AI로 만들기 순서로 안내합니다. 업로드가 안 되면 수동으로 하면 됩니다.

②VS Code나 터미널에서 AI를 쓰신다면 — 문장 하나로 설치

Claude Code, Codex, Antigravity처럼 VS Code나 터미널에서 쓰는 AI라면, 저장소 주소를 알려 주고 "설치해 줘"라고 하는 것으로 대부분 끝납니다.

  1. 먼저 아래 문장을 복사해 내 AI에 붙여넣습니다. 
    이 GitHub 저장소의 스킬(skills/amplify-math 폴더)을 내 스킬 폴더에 설치해 줘: https://github.com/getbetterwithu/amplify-math
    AI가 폴더를 받아 자기 스킬 폴더에 넣습니다. 설치 뒤 다시 시작하라고 하면 따르세요.
  2. 설치됐는지 확인합니다. AI를 다시 시작하고 "amplify-math 스킬이 설치돼 있어?"라고 물어 보세요. 설치돼 있다고 하면 끝입니다. 아니라고 하거나 헷갈리게 답하면 아래 직접 명령으로 설치하세요.
  3. 안 되면 직접 명령으로 설치합니다. 터미널에 아래를 한 줄씩 차례로 입력하세요. 설치 뒤 도구를 다시 시작합니다. 제품이 바뀌면 명령이 달라질 수 있습니다.

    Claude Code

    claude plugin marketplace add getbetterwithu/amplify-math
claude plugin install amplify-math@amplify-math

    Antigravity — 설치 결과에 skills : 1 processed가 보이면 됩니다.

    agy plugin install https://github.com/getbetterwithu/amplify-math
agy plugin list

    Codex CLI — codex plugin list에서 installed, enabled로 보이면 됩니다.

    codex plugin marketplace add getbetterwithu/amplify-math
codex plugin add amplify-math@amplify-math
codex plugin list
  4. 설치한 스킬은 에이전트의 권한으로 실행됩니다. 이 스킬은 규칙 문서와 지침만 들어 있고 내용은 GitHub ↗에서 볼 수 있습니다.

③설치 없이 붙여넣기 (가장 확실한 방법)

스킬을 만들지 않고 새 대화 첫 메시지에 규칙을 붙여넣어, 그 대화에서만 쓰는 방법입니다. 어떤 AI에서도 됩니다.

  1. 아래 버튼을 눌러 지침문과 규칙을 한 번에 복사합니다.
  2. 사용하는 AI의 새 대화 입력창에 붙여넣고 보냅니다.
  3. 이어서 "이 문장을 Amplify 수식으로 바꿔 줘: …"처럼 요청합니다. 새 대화를 열 때마다 다시 붙여넣어야 합니다.
