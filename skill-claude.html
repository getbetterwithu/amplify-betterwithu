STEP BY STEP · CLAUDE SKILL

Claude에 Amplify 수식 스킬 설치하기

Claude의 Skills 메뉴에 Amplify 수식 규칙을 올려 두면, 교과서 수식을 Amplify용으로 바꾸거나 쓴 수식을 검수할 때 Claude가 규칙을 알고 답합니다.

세 가지 방법 중 하나만 하면 됩니다

  1. Skill 업로드 — 내려받은 zip을 그대로 올립니다. 가장 간단합니다. (추천)
  2. Skill 만들기 — 이름·설명·내용 칸에 복사해 붙여넣습니다. 업로드가 안 될 때 씁니다.
  3. Claude로 만들기 — Claude와 대화하며 만듭니다. 규칙이 정확히 옮겨지지 않을 수 있어 마지막 순서입니다.

시작하기 전에

  • 메뉴 이름과 화면은 Anthropic이 바꿀 수 있습니다.
  • 무료 플랜 화면에서도 이 메뉴가 열렸습니다. 그래도 스킬이 동작하지 않으면 설정의 기능(Capabilities)에서 코드 실행 및 파일 생성이 켜져 있는지 확인하세요. 공식 안내가 스킬에 필요하다고 설명하는 설정입니다.
  • 업로드하면 보안 검사가 실행됩니다. 이 스킬의 파일은 GitHub ↗에서 내용을 볼 수 있고, 규칙 문서와 지침만 들어 있습니다.

0Skills 메뉴 열기

  1. Claude를 열고 왼쪽 메뉴에서 '사용자 지정'을 누릅니다.
    Claude 열기 ↗ 로그인 화면이 나오면 로그인하세요.
  2. 위쪽 탭 Skills · 커넥터 · 플러그인 중 Skills가 선택되어 있는지 확인합니다.
  3. 오른쪽 위의 + 추가 버튼을 누르면 Skill 업로드 · Skill 만들기 · Claude로 만들기 세 가지가 보입니다(그림 1). 아래에서 하나를 고르세요.

1Skill 업로드 추천

zip을 풀지 않고 그대로 올립니다. 업로드 화면이 ".zip 또는 .skill 파일에는 SKILL.md 파일이 포함되어야 한다"고 안내하며, 이 zip은 그 조건을 맞춰 두었습니다.

  1. 스킬 zip을 내려받습니다. 압축은 풀지 않습니다.
    스킬 zip 내려받기
  2. + 추가 → Skill 업로드를 누릅니다(그림 1).
  3. 'Skill 파일' 영역에 zip을 끌어다 놓거나 '찾아보기'로 고릅니다(그림 2).
  4. 아래의 '업로드' 버튼을 누릅니다. 업로드할 때 보안 검사가 실행됩니다. 파일을 고르기 전에는 이 버튼이 흐리게 비활성입니다.
  5. Skills 목록에 amplify-math가 보이고 켜져 있으면 끝입니다. 아래 시험으로 확인하세요.

업로드가 거절되거나 목록에 보이지 않거나, 올린 뒤 규칙을 모르는 것처럼 답하면 2번 방법으로 하세요.

2Skill 만들기

이름, 설명, 내용 세 곳에 아래 글을 복사해 붙여넣습니다(그림 3).

  1. + 추가 → Skill 만들기를 누르면 'Skill 만들기' 창이 열립니다.
  2. Skill 이름 칸에 아래 이름을 입력합니다. 
    amplify-math
  3. 설명 칸에 붙여넣습니다. 
    Amplify Classroom(Desmos)의 메모·수식 답변·CL에 들어갈 수학 수식을 작성·검수·변환한다. 교과서 수식을 Amplify용 백틱 LaTeX로 옮기거나, 쓴 수식이 Amplify에서 그려질지 확인해 달라는 요청에 사용한다.
  4. 아래 큰 칸(줄 번호가 있는 편집 영역)에 지침문과 규칙 전체를 붙여넣습니다.
    지침과 규칙을 모두 붙여넣으세요(약 6,600자). 오류가 나면 설치 없이 쓰기를 쓰세요.
  5. 오른쪽 아래의 만들기 버튼을 눌러 저장합니다.

3Claude로 만들기

Claude의 skill-creator가 묻는 내용에 아래 답을 보내는 방법입니다. 규칙을 요약해 다시 쓰므로 정확도는 앞의 두 방법보다 낮을 수 있습니다.

  1. + 추가 → Claude로 만들기를 누르면 새 대화 입력창에 영어 문장이 자동으로 채워집니다(그림 4). 그대로 보냅니다. "Let's create a skill together using your skill-creator skill. First ask me what the skill should do."라는 뜻으로, 영어로 채워져도 한국어로 답하셔도 됩니다.
  2. 규칙 파일을 내려받아 대화에 첨부합니다.
    rules.md 내려받기 입력창 왼쪽의 +로 파일을 올립니다.
  3. Claude가 스킬이 무엇을 해야 하는지 물으면 아래 답을 복사해 보냅니다. 
    목표: 중학교 수학 교사가 Amplify Classroom(Desmos)의 메모·수식 답변·CL에 넣을 수학 수식을 작성·검수·변환한다.
사용할 때: "Amplify 수식", "교과서 수식을 Amplify로 바꿔줘", "이 수식이 Amplify에서 그려지나요" 같은 요청.
규칙: 첨부한 rules.md를 규칙의 근거로 삼는다. 수식은 백틱으로 감싸고 ~~~ 코드 블록에 담아 준다. rules.md의 대체표에 걸리는 명령은 고쳐서 주고, 목록에 없는 명령은 "확인되지 않았다"고 말한다. 메모·수식 답변 칸에는 붙여넣기로 넣어야 한다고 안내한다.
  4. 만들어진 스킬에 대체표(\therefore→∴ 등)가 빠졌으면 "rules.md의 대체표를 그대로 넣어 줘"라고 요청합니다.

✓잘 설치됐는지 확인하고 시험하기

  1. 먼저 등록됐는지 확인합니다. 사용자 지정 → Skills의 내 항목에 amplify-math가 보이고 켜져 있어야 합니다.
  2. 새 채팅을 열고 아래를 보냅니다. 
    amplify-math 스킬을 사용해서, 삼각형 ABC와 삼각형 DEF가 닮음이고 따라서 각 A와 각 D가 같다는 문장을 Amplify 메모용 수식으로 바꿔 줘.
  3. 이렇게 나오면 성공입니다. 닮음은 ∽, 따라서는 ∴를 쓰고, 점 이름은 \mathrm{}으로 감싸고, 기호 앞뒤에 \ 가 들어 있고, 수식이 백틱과 코드 블록으로 담겨 있습니다.
  4. 한 번 더 시험합니다. 
    amplify-math 스킬로 답해 줘. \therefore 와 \equiv 를 Amplify에서 써도 되나요?

    "그려지지 않고 칸이 비워진다, 대신 ∴ 와 ≡ 를 쓴다"고 답하면 규칙을 알고 있는 것입니다.
  5. 결과를 복사해서 붙여넣기로 Amplify 메모에 넣습니다. 키보드로 직접 치면 수식으로 바뀌지 않습니다.

＋설치 없이 쓰기 (가장 확실한 방법)

스킬을 만들지 않고, 새 대화 첫 메시지에 규칙을 붙여넣어 그 대화에서만 쓰는 방법입니다. Skills 메뉴가 안 보여도 됩니다.

  1. 아래 버튼을 눌러 지침문과 규칙을 한 번에 복사합니다.
  2. Claude 새 채팅의 입력창에 붙여넣고 보냅니다.
  3. 이어서 "이 문장을 Amplify 수식으로 바꿔 줘: …"처럼 요청합니다. 새 대화를 열 때마다 다시 붙여넣어야 합니다.
