사용 방법을 선택하세요

짧은 체험을 위한 임시 방식입니다. 운영자의 Gemini 키는 서버 환경변수에만 있으며 브라우저로 전달되지 않습니다.
개인 키는 이 브라우저의 로컬 저장소에만 보관되며 Gemini API 호출에만 사용됩니다. 공용 기기에서는 사용하지 마세요.
API 키를 넣으면 사진을 읽는 모델만 골라 목록으로 보여 드립니다. 직접 입력할 필요 없이 고르면 됩니다. 최신 모델이 위에 옵니다.
