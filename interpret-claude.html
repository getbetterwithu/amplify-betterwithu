STEP BY STEP · CLAUDE SKILL

Claude에 CL 해석 스킬 설치하기

Claude의 Skills 메뉴에 CL 해석 스킬을 올려 두면, CL 코드를 붙여넣거나 캡처를 올릴 때 Claude가 지식 파일을 참고해 줄별로 풀이합니다.

두 가지 방법 중 하나만 하면 됩니다

  1. Skill 업로드 — 내려받은 zip을 그대로 올립니다. 가장 간단합니다. (추천)
  2. 프로젝트로 쓰기 — 스킬 메뉴가 없거나 업로드가 안 될 때 지침을 붙여넣고 파일을 올립니다.

시작하기 전에

  • 이 zip을 Claude에 올려 확인한 것은 아닙니다. 메뉴 화면은 수식 스킬 안내에서 확인한 것이고, 이 스킬은 수식 스킬(약 20KB)보다 훨씬 큽니다(약 126KB). 되지 않으면 아래 '잘 안 될 때'를 보세요.
  • 메뉴 이름과 화면은 Anthropic이 바꿀 수 있습니다.
  • 무료 플랜 화면에서도 이 메뉴가 열렸습니다. 그래도 스킬이 동작하지 않으면 설정의 기능(Capabilities)에서 코드 실행 및 파일 생성이 켜져 있는지 확인하세요. 공식 안내가 스킬에 필요하다고 설명하는 설정입니다.
  • 업로드하면 보안 검사가 실행됩니다. 이 스킬의 파일은 GitHub ↗에서 내용을 볼 수 있고, 지침과 지식 문서(.md)만 들어 있고 실행 파일은 없습니다.

0Skills 메뉴 열기

  1. Claude를 열고 왼쪽 메뉴에서 '사용자 지정'을 누릅니다.
    Claude 열기 ↗ 로그인 화면이 나오면 로그인하세요.
  2. 위쪽 탭 Skills · 커넥터 · 플러그인 중 Skills가 선택되어 있는지 확인합니다.
  3. 오른쪽 위의 + 추가 버튼을 누르면 Skill 업로드 · Skill 만들기 · Claude로 만들기 세 가지가 보입니다(그림 1). 아래에서 하나를 고르세요.

1Skill 업로드 추천

zip을 풀지 않고 그대로 올립니다. 업로드 화면이 ".zip 또는 .skill 파일에는 SKILL.md 파일이 포함되어야 한다"고 안내하며, 이 zip은 그 조건을 맞춰 두었습니다.

  1. 스킬 zip을 내려받습니다. 압축은 풀지 않습니다.
    스킬 zip 내려받기
  2. + 추가 → Skill 업로드를 누릅니다(그림 1).
  3. 'Skill 파일' 영역에 zip을 끌어다 놓거나 '찾아보기'로 고릅니다(그림 2).
  4. 아래의 '업로드' 버튼을 누릅니다. 업로드할 때 보안 검사가 실행됩니다. 파일을 고르기 전에는 이 버튼이 흐리게 비활성입니다.
  5. Skills 목록에 cl-interpreter가 보이고 켜져 있으면 끝입니다. 아래 시험으로 확인하세요.

업로드가 거절되거나 목록에 보이지 않거나, 올린 뒤 규칙을 모르는 것처럼 답하면 2번 방법으로 하세요.

2프로젝트로 쓰기

스킬 메뉴가 없거나 업로드가 안 될 때 쓰는 대안입니다. 이 스킬은 지식 파일이 커서 전부 붙여넣을 수 없으므로 지침은 붙여넣고 지식 파일은 올립니다. 저장소 안내를 정리한 방법으로 직접 확인하지는 못했습니다.

  1. 지침문을 복사합니다(약 9KB).
  2. Claude 왼쪽 메뉴의 프로젝트에서 새 프로젝트를 만들고, 지침(Instructions) 칸에 붙여넣습니다.
  3. 스킬 zip을 내려받아 풀고 안의 파일을 올립니다. INDEX.md, knowledge/ 안 8개, reference/ 안 3개입니다. 프로젝트의 지식(Project knowledge)에 올립니다.
    스킬 zip 내려받기
  4. 저장한 뒤 아래 시험으로 확인하세요. 이 방법에서는 요청 첫머리의 "cl-interpreter 스킬을 사용해서"를 빼고 보내도 됩니다.

✓잘 설치됐는지 확인하고 시험하기

  1. 먼저 등록됐는지 확인합니다. 사용자 지정 → Skills의 내 항목에 cl-interpreter가 보이고 켜져 있어야 합니다.
  2. 새 채팅을 열고 아래를 보냅니다. 
    cl-interpreter 스킬을 사용해서 아래 Computation Layer 코드를 줄별로 풀이해 줘.

컴포넌트: input1
hidden: btn1.pressCount > 2
correct: this.numericValue > 9.99 and this.numericValue < 10.01
  3. 이렇게 나오면 성공입니다. 붙여넣은 텍스트의 코드 조각(hidden: btn1.pressCount > 2 등)을 인용하며 줄별로 풀이하고, 문장 끝에 공식 문서·코드 추론·추가검증필요 같은 출처 표시가 붙습니다.
  4. 실제 수업 코드는 캡처로 올리는 것이 기본입니다. 코드를 올리는 방법을 보세요.

잘 안 될 때

스킬 메뉴나 추가 버튼이 없습니다
학교·회사 계정이면 관리자 설정 때문일 수 있습니다. 그때는 프로젝트로 쓰기를 쓰세요.
업로드가 거절됩니다
zip의 압축을 풀지 않은 상태인지 확인하세요. "SKILL.md가 없다"는 오류는 zip 안에 파일이 바로 들어 있을 때 나옵니다. 이 zip은 cl-interpreter 폴더째 압축되어 있습니다. 보안 검사에서 걸렸다면 프로젝트로 쓰기를 쓰세요.
올렸는데 CL을 모르는 것처럼 답합니다
스킬이 켜져 있는지 확인하고, 요청 첫머리에 "cl-interpreter 스킬을 사용해서"라고 이름을 말해 보세요. 그래도 안 되면 설정의 기능(Capabilities)에서 코드 실행 및 파일 생성이 켜져 있는지 확인하세요.
답이 "자료에 없습니다"인데 파일에는 있는 것 같습니다
지식 파일이 커서 일부만 읽힐 수 있습니다. 질문에 컴포넌트 이름과 sink 이름을 함께 적어 보세요.
화면이 그림과 다릅니다
메뉴 이름에서 Skills와 추가를 찾으세요. 공식 설명은 Claude 스킬 공식 안내 ↗에서 볼 수 있습니다.
