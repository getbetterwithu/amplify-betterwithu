CL 해석 스킬 설치 안내 v0.3.2

내가 쓰는 AI가 Amplify Computation Layer(CL) 문법을 알고 코드를 줄별로 풀이하게 하는 스킬입니다. CL 코드를 붙여넣거나 캡처를 올리면 분석하고, sink·source 같은 CL 문법 질문에도 답합니다. Claude, ChatGPT, Gemini 중 하나만 성공해도 충분합니다.

어느 방법이 나에게 맞나요?

  1. AI를 대화창으로만 써 봤다 → 아래 ① 처음이라면. 코딩 지식 없이 화면만 따라 하면 됩니다.
  2. VS Code나 터미널에서 Claude Code, Codex, Antigravity 같은 AI를 쓴다 → ② 문장 하나로 설치 (현재 공개 링크 일시 중단, 안내 참고).
  3. 스킬 메뉴가 없거나 업로드가 안 된다 → ③ 지침을 붙여넣고 파일 올리기 (Claude·Gemini).

알아 두세요

  • 스킬은 개정 중이며 AI의 분석은 틀릴 수 있습니다. 수업에 적용하기 전에 원본 CL 코드와 CL 학습자료로 확인해 주세요.
  • 이 스킬의 문법 지식 중 일부는 아직 Amplify에서 실행해 확인하지 않았습니다. 답의 문장 끝에 붙는 출처 표시(공식 문서, 판정, 추가검증필요, 예상, 코드 추론)로 확신 정도를 구분합니다.
  • ChatGPT 웹은 올려서 등록되고 시험 문장에 풀이가 나오는 것까지 확인했고, Claude·Gemini와 ③ 방법은 아직 직접 확인하지 못했습니다. 메뉴는 수시로 바뀔 수 있으니 되지 않으면 각 안내의 '잘 안 될 때'를 보세요.

⚠️ 공개 저장소를 통한 설치 일시 중단 안내

현재 Amplify 이용약관 및 저작권 관련 검토로 인해, 공개 저장소를 통한 직접 설치(저장소 링크 및 플러그인 CLI 명령어)는 잠시 중단되었습니다. 추후 Amplify의 공식 승인을 받거나 협의가 완료되면 이 페이지에 실제 저장소 링크와 명령어가 다시 복원될 예정입니다. 변경 사항이 있을 수 있으니 페이지를 자주 확인(모니터링)해 주세요. 현재는 연수 현장에서 배포해 드리는 zip 파일을 통한 설치를 권장합니다.

  1. (설치 방식 안내) 저장소가 공개 운영될 때는 아래와 같이 한 줄 문장으로 AI에게 설치를 요청하는 방식입니다. 
    이 GitHub 저장소의 스킬(skills/cl-interpreter 폴더)을 내 스킬 폴더에 설치해 줘: [저장소 주소 — 승인 후 공개 재개 예정]
    AI가 저장소 폴더를 읽어 자기 스킬 폴더에 자동으로 등록합니다. (현재는 승인 검토 중으로 링크가 비활성화되어 있습니다)
  2. 터미널 명령어를 통한 설치 (예시)

    Claude Code / Antigravity / Codex CLI

    # 공식 승인 및 공개 재개 후 아래 명령어로 설치할 수 있습니다:
claude plugin marketplace add getbetterwithu/amplify-cl-interpreter
claude plugin install amplify-cl-interpreter@amplify-cl-interpreter

agy plugin install https://github.com/getbetterwithu/amplify-cl-interpreter
codex plugin marketplace add getbetterwithu/amplify-cl-interpreter
    ※ 저장소 링크가 복원되면 실제 복사용 버튼과 주소가 활성화됩니다.

③스킬 메뉴가 없거나 안 될 때 — 지침을 붙여넣고 파일 올리기

이 스킬은 지식 파일이 커서(압축 전 약 480KB) 수식 스킬처럼 전부 붙여넣을 수 없습니다. 대신 짧은 지침문은 붙여넣고, 지식 파일은 올립니다. 저장소 안내를 정리한 방법으로 직접 확인하지는 못했습니다.

  1. 아래 버튼으로 지침문(약 9KB)을 복사합니다.
  2. 내 AI의 맞춤 도구를 만들고 지침 칸에 붙여넣습니다. Claude는 프로젝트, Gemini는 Gem입니다. ChatGPT는 GPT를 더 이상 만들 수 없어 이 방법을 쓸 수 없습니다. 자세한 순서는 위 ①의 AI별 안내에 있습니다.
  3. 스킬 zip을 풀어서 안의 파일을 지식(Knowledge)으로 올립니다. INDEX.md, knowledge/ 안 8개, reference/ 안 3개입니다.
  4. 지식 파일이 커서 답이 "자료에 없습니다"로 나오는데 파일에는 있는 경우가 있습니다. 질문에 컴포넌트 이름과 sink 이름을 함께 적어 보세요.

✎코드는 이렇게 올립니다

  1. 기본은 캡처입니다. 편집기에서 줄 번호가 보이게 캡처해 올리세요. 줄 번호가 있으면 어느 줄을 풀이한 것인지 정확히 짚을 수 있습니다.
  2. 긴 코드는 캡처와 텍스트를 함께 올리세요. 캡처로 줄 번호를, 텍스트로 정확한 글자를 확인합니다.
  3. 텍스트만 붙여넣을 때는 첫 줄에 컴포넌트 이름을 적으세요. 붙여넣은 텍스트는 줄 번호와 어긋나기 쉬워서, 줄 번호 대신 코드 조각을 인용해 풀이합니다. 
    컴포넌트: input1
hidden: btn1.pressCount > 2
correct: this.numericValue > 9.99 and this.numericValue < 10.01
  4. 더 정확한 해석을 원하면 코드가 읽는 다른 컴포넌트의 값(예: input1.numericValue)이나 그래프 안의 변수의 CL도 함께 보내 주세요. 풀이 끝에 어떤 자료가 더 필요한지 알려 줍니다.

⬇파일 안내

📦 스킬 배포 파일 안내 (연수 배포용)

CL 해석 스킬 zip 파일(cl-interpreter.zip)은 저작권 및 이용약관 검토에 따라 사이트 직접 다운로드를 중단하고, 교사 연수 현장에서 참가자분들께 직접 전달해 드리고 있습니다. 전달받으신 zip 파일을 압축 해제 없이(또는 안내에 따라 폴더째) 각 AI 도구에 등록해 사용하시면 됩니다.

zip 안에는 지침(SKILL.md), 저작권 및 출처 안내(NOTICE.md), 지식 문서들이 마크다운(.md)으로 들어 있습니다. 현재 버전은 v0.3.2입니다.
