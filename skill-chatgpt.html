ChatGPT에 Amplify 수식 스킬 설치하기

ChatGPT의 스킬 메뉴에 Amplify 수식 규칙을 올려 두면, 교과서 수식을 Amplify용으로 바꾸거나 쓴 수식을 검수할 때 ChatGPT가 규칙을 알고 답합니다.

세 가지 방법 중 하나만 하면 됩니다

  1. 컴퓨터에서 업로드 — 내려받은 zip을 그대로 올립니다. 가장 간단합니다. (추천)
  2. 편집기로 생성 — 이름·설명·지침 칸에 복사해 붙여넣습니다. 업로드가 안 될 때 씁니다.
  3. 채팅으로 만들기 — ChatGPT와 대화하며 만듭니다. 규칙이 정확히 옮겨지지 않을 수 있어 마지막 순서입니다.

시작하기 전에

  • 이 안내는 2026-10-26 화면 기준입니다. 메뉴 이름과 화면은 OpenAI가 바꿀 수 있습니다.
  • 무료 계정에서 스킬 메뉴를 쓸 수 있는지는 확인하지 못했습니다. 메뉴가 보이지 않으면 아래 설치 없이 쓰기를 쓰세요.
  • 업로드 창은 "타사 스킬은 위험성이 더 높으며 데이터에 액세스하려 할 수 있으니 신뢰할 수 있는 소스의 스킬만 업로드하고 사용 전에 검토하라"고 안내합니다. 이 스킬의 파일은 GitHub ↗에서 내용을 볼 수 있고, 규칙 문서와 지침만 들어 있습니다.

0스킬 메뉴 열기

  1. ChatGPT 스킬 화면을 엽니다.
    ChatGPT 스킬 열기 ↗ 로그인 화면이 나오면 로그인하세요. 이 주소로 열리지 않으면 ChatGPT 왼쪽 메뉴에서 플러그인이나 스킬을 찾으세요.
  2. 위쪽 탭이 플러그인 · 스킬이고 스킬이 선택되어 있는지 확인합니다.
  3. 오른쪽 위의 추가 버튼을 누르면 채팅으로 만들기 · 편집기로 생성 · 컴퓨터에서 업로드 세 가지가 보입니다(그림 1). 아래에서 하나를 고르세요.

1컴퓨터에서 업로드 추천업로드 시험 예정

Gemini와 달리 zip을 풀지 않고 그대로 올립니다. 업로드 창이 .zip, .skill, SKILL.md를 받는다고 안내합니다.

  1. 스킬 zip을 내려받습니다. 압축은 풀지 않습니다.
    스킬 zip 내려받기
  2. 추가 → 컴퓨터에서 업로드를 누릅니다(그림 1).
  3. '스킬 업로드' 창에 zip 파일을 끌어다 놓거나, 창을 눌러 파일을 고릅니다(그림 2). 파일당 최대 크기는 25MB이고, 이 zip은 20KB 남짓입니다.
  4. '설치됨' 목록에 amplify-math가 보이면 끝입니다. 아래 시험으로 확인하세요.

업로드가 거절되거나 목록에 보이지 않거나, 올린 뒤 규칙을 모르는 것처럼 답하면 2번 방법으로 하세요.

2편집기로 생성

이름, 설명, 지침 세 곳에 아래 글을 복사해 붙여넣습니다(그림 3).

  1. 추가 → 편집기로 생성을 누릅니다. 편집기 화면이 열립니다.
  2. 이름 칸에 아래 이름을 입력합니다. 소문자와 숫자, 단어 사이 하이픈 하나만, 최대 64자라는 안내가 화면에 있습니다. 
    amplify-math
  3. 설명 칸에 붙여넣습니다. 500자까지 쓸 수 있고 이 설명은 134자입니다. 
    Amplify Classroom(Desmos)의 메모·수식 답변·CL에 들어갈 수학 수식을 작성·검수·변환한다. 교과서 수식을 Amplify용 백틱 LaTeX로 옮기거나, 쓴 수식이 Amplify에서 그려질지 확인해 달라는 요청에 사용한다.
  4. 아래 큰 칸("스킬 지침을 작성하세요")에 지침문과 규칙 전체를 붙여넣습니다.
    내용이 길어서 칸이 받지 못하면(오류가 나거나 잘리면) 설치 없이 쓰기를 쓰세요. 글자 수 제한은 아직 확인하지 못했습니다.
  5. 오른쪽 위의 생성 버튼을 눌러 저장합니다.

3채팅으로 만들기

ChatGPT의 skill-creator가 묻는 내용에 아래 답을 보내는 방법입니다. 규칙을 요약해 다시 쓰므로 정확도는 앞의 두 방법보다 낮을 수 있습니다.

  1. 추가 → 채팅으로 만들기를 누르면 새 대화에 "skill-creator를 사용해서 스킬을 만드는 걸 도와줘. 대화하듯 진행하고, 먼저 스킬이 어떤 일을 해야 하는지 물어봐."가 입력됩니다(그림 4). 그대로 보냅니다.
  2. 규칙 파일을 내려받아 대화에 첨부합니다.
    rules.md 내려받기 입력창 왼쪽의 +로 파일을 올립니다.
  3. ChatGPT가 목적을 물으면 아래 답을 복사해 보냅니다. 
    목표: 중학교 수학 교사가 Amplify Classroom(Desmos)의 메모·수식 답변·CL에 넣을 수학 수식을 작성·검수·변환한다.
사용할 때: "Amplify 수식", "교과서 수식을 Amplify로 바꿔줘", "이 수식이 Amplify에서 그려지나요" 같은 요청.
규칙: 첨부한 rules.md를 규칙의 근거로 삼는다. 수식은 백틱으로 감싸고 ~~~ 코드 블록에 담아 준다. rules.md의 대체표에 걸리는 명령은 고쳐서 주고, 목록에 없는 명령은 "확인되지 않았다"고 말한다. 메모·수식 답변 칸에는 붙여넣기로 넣어야 한다고 안내한다.
  4. 만들어진 스킬에 대체표(\therefore→∴ 등)가 빠졌으면 "rules.md의 대체표를 그대로 넣어 줘"라고 요청합니다.

✓잘 설치됐는지 확인하고 시험하기

  1. 먼저 등록됐는지 확인합니다. 스킬 화면의 설치됨 목록에 amplify-math가 보여야 합니다.
  2. 새 채팅을 열고 아래를 보냅니다. 
    amplify-math 스킬을 사용해서, 삼각형 ABC와 삼각형 DEF가 닮음이고 따라서 각 A와 각 D가 같다는 문장을 Amplify 메모용 수식으로 바꿔 줘.
  3. 이렇게 나오면 성공입니다. 닮음은 ∽, 따라서는 ∴를 쓰고, 점 이름은 \mathrm{}으로 감싸고, 기호 앞뒤에 \ 가 들어 있고, 수식이 백틱과 코드 블록으로 담겨 있습니다.
  4. 한 번 더 시험합니다. 
    amplify-math 스킬로 답해 줘. \therefore 와 \equiv 를 Amplify에서 써도 되나요?

    "그려지지 않고 칸이 비워진다, 대신 ∴ 와 ≡ 를 쓴다"고 답하면 규칙을 알고 있는 것입니다.
  5. 결과를 복사해서 붙여넣기로 Amplify 메모에 넣습니다. 키보드로 직접 치면 수식으로 바뀌지 않습니다.

＋설치 없이 쓰기 (가장 확실한 방법)

스킬을 만들지 않고, 새 대화 첫 메시지에 규칙을 붙여넣어 그 대화에서만 쓰는 방법입니다. 스킬 메뉴가 안 보여도 됩니다.

  1. 아래 버튼을 눌러 지침문과 규칙을 한 번에 복사합니다.
  2. ChatGPT 새 채팅의 입력창에 붙여넣고 보냅니다.
  3. 이어서 "이 문장을 Amplify 수식으로 바꿔 줘: …"처럼 요청합니다. 새 대화를 열 때마다 다시 붙여넣어야 합니다.

잘 안 될 때

스킬 메뉴가 없거나 추가 버튼이 없습니다
요금제나 계정 종류에 따라 메뉴가 없을 수 있습니다. 학교·회사 계정이면 관리자 설정 때문일 수 있습니다. 그때는 설치 없이 쓰기가 가장 확실합니다.
업로드가 거절됩니다
zip의 압축을 풀지 않은 상태인지, 파일 크기가 25MB 이하인지 확인하세요. 그래도 안 되면 2번(편집기)을 쓰세요.
올렸는데 규칙을 모르는 것처럼 답합니다
요청 첫머리에 "amplify-math 스킬을 사용해서"라고 이름을 말해 보세요. 그래도 안 되면 편집기(2번)나 붙여넣기를 쓰세요.
