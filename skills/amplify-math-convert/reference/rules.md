# Amplify 수식 규칙표 (규칙의 원본)

- **실측일:** 2026-10-23
- **실측 경로:** `classroom.amplify.com` 활동 편집기의 Desmos 계산기 수식 칸에 한 항씩 넣고 렌더 여부를 판독 (72항, 렌더됨 53 / 안 그려짐 19)
- **근거 파일:** `실측보고서.md`(이 폴더), 원데이터 `amplify-one-by-one-render.json`, 기계용 표 `commands.json`
- **이 표에 없는 LaTeX는 쓰지 않는다.** 모델이 기억하는 일반 LaTeX·amsmath로 보강하지 않는다.
- Amplify가 MathQuill을 바꾸면 이 표도 바뀔 수 있다. 결과가 이상하면 실측을 다시 한다.

## 판단 순서
1. **허용 표(A)**에 있으면 쓴다.
2. **치환 표(B)**에 있으면 그 대체 표기를 쓴다.
3. 그 밖의 명령은 **내지 않는다.** 꼭 필요하면 백틱 밖 한글로 풀어 쓴다.

## A. 허용 (Amplify 실측에서 그려짐)
| 분류 | 명령 |
|---|---|
| 분수·근 | `\frac{}{}` `\sqrt{}` `\sqrt[3]{}` `\nthroot{3}{}` |
| 기하 | `\overline{}` `\overarc{}` `\overleftrightarrow{}` `\triangle` `\angle` `\measuredangle` `\perp` `\parallelogram` `\bigcirc` `\square` `\degree` |
| 관계·연산 | `=` `\neq` `\leq` `\geq` `<` `>` `\times` `\div` `\cdot` `\pm` `\to` `\infty` `\nsim` |
| 글꼴·색 | `\mathrm{}` `\mathbf{}` `\textcolor{red}{}` |
| 괄호 | `\left(` … `\right)` |
| 첨자 | `^2` `^{10}` `_1` `_{12}` |
| 공백 | `\ ` (백슬래시+공백) |
| 기타 (중등 변환에서는 거의 안 씀) | `\sum` `\prod` `\int` `\binom{}{}` `\lim` `\sin` 등 함수 이름 `\vec{}` `\hat{}` `\forall` `\percent` |

- `\lim`은 **그려진다.** 중등 교과서 변환에서 쓸 일이 드물 뿐이다(렌더 문제가 아니다).
- `\vec{}` `\hat{}`은 그려지지만 화면 낭독 문구에 `undefined`가 섞인다. 꼭 필요할 때만 쓴다.
- `\percent`는 `% of`로 보인다. 퍼센트 기호는 `\%` 대신 백틱 밖 `%`를 쓴다.

## B. 치환 (그대로 쓰면 안 되는 것)
| 쓰지 말 것 | 이유 | 대신 쓸 것 |
|---|---|---|
| `\therefore` | 안 그려짐 | `∴` |
| `\because` | 안 그려짐 | `∵` |
| `\equiv` | 안 그려짐 | `≡` (합동) |
| `\Rightarrow` `\implies` | 안 그려짐 | `⇒` |
| `\Leftrightarrow` | 안 그려짐 | `⇔` (유니코드 자체는 미실측) |
| `\text{…}` | 안 그려짐 | 한글·설명은 백틱 **밖** |
| `\quad` | 안 그려짐 | `\ ` |
| `\ldots` `\cdots` | 안 그려짐 | 백틱 밖 `……` |
| `\cbrt{8}` | 안 그려짐 | `\sqrt[3]{8}` |
| `40^\circ` | 안 그려짐 | `40\degree` |
| `\dfrac` `\cfrac` | 그려지나 `\frac`과 같음 | `\frac` |
| `\sim` | 물결 `~`로 보임 | 닮음 `∽` |
| `\parallel` | 곧은 `∥`로 보임 | 평행 `⫽` |
| `\cong` | `≅`로 보임 | 합동은 보통 `≡` (교과서 표기 확인) |
| `\underbrace` `\overbrace` `\mathbb` `\propto` `\bot` `\backsim` `\leftarrow` | 안 그려짐 | 쓰지 않음 (`\bot` 대신 `\perp`) |

- 실측에서 그려진 유니코드: `∽ ≡ ⫽ ∴ ∵ ⇒`. `⇔ ≒ ∝ …`는 아직 실측하지 않았다.
- 유니코드 관계 기호(`∽ ≡ ⫽ ∴ ∵ ⇒ ⇔`) 앞뒤에는 `\ `을 넣는다. 없으면 글자가 달라붙는다.

## C. 표기 규칙
1. 수식은 백틱(`` ` ``)으로 감싼다. 한글 설명·번호·괄호 설명(`(AA 닮음)`, `…… ①`)은 백틱 밖.
2. 점 이름(A, B, C …)은 `\mathrm{}`으로 감싼다: `\triangle\mathrm{ABC}`, `\overline{\mathrm{BD}}`. 변·변수 문자(a, b, x, y)는 감싸지 않는다.
3. 등호 `=`와 비례식 콜론 `:` 앞뒤에는 `\ `을 넣는다. `+ − × ÷` 앞뒤에는 넣지 않는다.
4. 교과서의 줄바꿈과 들여쓰기를 살린다.

## D. 출력 대상별 차이
| 대상 | 형식 |
|---|---|
| **메모·글 칸에 붙여넣기 (기본)** | 백틱 + 위 규칙 |
| **CL 코드 문자열** (`content: "…"`) | 같은 내용에서 백슬래시를 두 번(`\\frac`) |
| **계산기·수식 입력 칸** | 백틱 없이 수식만. 안 그려지는 명령은 똑같이 금지 |

- 주 실측 근거는 계산기 수식 칸이다. 메모 백틱 경로는 샘플(`\therefore`, `\lim`이 명령으로 바뀌지 않음)만 확인했고, 수식 답변·CL 경로의 전항 표는 아직 없다.

## E. 미실측 명령
MathQuill 등록부에는 있으나 Amplify에서 실측하지 않은 명령(`commands.json`의 `registry_unmeasured`, 140개)은 **쓰지 않는다.** `\cbrt`처럼 등록부에는 있어도 Amplify에서 안 그려지는 경우가 있었다.
