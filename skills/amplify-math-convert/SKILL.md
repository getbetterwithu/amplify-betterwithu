# Amplify 수식 변환 스킬 (v0.1.0)

## 역할
중학교 교과서 수식을 **Amplify 메모에 붙일 문자열로만** 옮긴다. 설명을 덧붙이거나 내용을 지어내지 않는다.

Amplify(Desmos)는 수식을 **MathQuill**로 그린다. 저장 형식은 LaTeX처럼 보이지만 **표준 LaTeX 전체가 아니라 그려지는 명령의 부분집합**만 쓸 수 있다. 습관대로 일반 LaTeX(`\text`, `\quad`, `\therefore`, `\equiv` 등)를 쓰면 Amplify에서 빈칸으로 나온다.

## 규칙의 원본
- **`reference/rules.md`를 먼저 읽고 그대로 따른다.** 이 표에 없는 LaTeX는 쓰지 않는다. 기억하는 일반 LaTeX로 보강하지 않는다.
- 근거: `reference/실측보고서.md`(2026-10-23 Amplify 실측), 기계용 표 `reference/commands.json`.
- 판단 순서: **허용 표(A)에 있으면 사용 → 치환 표(B)에 있으면 대체 표기 → 그 외는 내지 않음.**

## 절차
1. **입력 받기.** 이미지(캡처) 또는 텍스트. 출력 대상을 확인한다(기본은 메모 붙여넣기). CL 코드 문자열이나 계산기 칸에 넣을 것이면 `rules.md` D절을 따른다.
2. **옮기기.** 이미지에 보이는 수학 내용만 옮긴다. 없는 것을 지어내지 않고, 있는 것을 빠뜨리지 않는다. 줄바꿈과 들여쓰기를 살린다. 읽기 애매한 글자는 추측하지 말고 결과 아래 경고 줄에 적는다.
3. **검사.** 결과를 임시 파일로 저장하고 실행한다.
   ```
   python3 scripts/check.py 결과.txt --fix -o 결과.txt [--target memo|cl|calc]
   ```
   `[고침]`은 자동으로 고친 것, `[경고]`는 사람이 확인할 것이다. 경고가 있으면 원문(이미지)을 다시 보고 직접 고친 뒤 다시 실행한다.
4. **미리보기.** 파일을 만들고 열 수 있는 환경(Codex, Claude Code 등)이면 실행한다.
   ```
   python3 scripts/preview.py 결과.txt
   ```
   MathQuill로 그린 HTML이 브라우저에서 열린다. 빨간 글자는 그리지 못한 수식이다. 미리보기를 띄울 수 없는 환경이면 이 단계를 건너뛰고 그 사실을 한 줄로 알린다.
5. **출력.** 변환 결과를 **코드블록 하나**로 준다(복사용). 머리말·설명을 붙이지 않는다. 검사에서 남은 경고와 읽기 애매한 글자가 있을 때만 코드블록 아래에 한 줄씩 적는다. 수학 내용이 없으면 "이미지에서 수학 내용을 찾지 못했습니다."라고만 답한다.

## 자주 틀리는 함정
| 하지 말 것 | 할 것 |
|---|---|
| `\equiv` (합동) | `≡` |
| `\sim` (물결로 보임) | 닮음 `∽` |
| `\parallel` (곧은 ∥) | 평행 `⫽` |
| `\therefore` `\because` | `∴` `∵` |
| `\Rightarrow` `\implies` | `⇒` |
| `\text{…}` | 한글은 백틱 **밖** |
| `\quad` | `\ ` |
| `\cbrt{}` | `\sqrt[3]{}` |
| `^\circ` | `\degree` |
| `\dfrac` `\cfrac` | `\frac` |
| 점 이름 그대로 `ABC` | `\mathrm{ABC}` |
| 유니코드 관계 기호를 붙여 쓰기 | 앞뒤에 `\ ` |

## 출력 직전 자기 검사
1. 안 그려지는 명령(`rules.md` B·E)이 남았는가
2. `\sim` `\parallel` `\equiv` `\cong`이 교과서 기호와 맞는가
3. 한글이 백틱 안에 들어갔는가
4. 점 이름에 `\mathrm`이 빠졌는가
5. `∽ ≡ ⫽ ∴ ∵ ⇒` 앞뒤에 `\ `이 있는가
6. 이미지에 없는 내용을 넣거나, 있는 내용을 빠뜨렸는가

## 하지 않는 것
- CL 코드 해석은 이 스킬의 일이 아니다(CL 해석 스킬을 쓴다).
- 학생 개인정보가 보이는 이미지는 다루지 않고, 잘라서 다시 달라고 안내한다.
