# Amplify 수식 작성 스킬

Amplify Classroom의 수식은 표준 LaTeX 전체가 아니라 **등록된 명령만** 그립니다. 지원하지 않는 명령은 글자로 남지 않고 칸이 통째로 비워집니다. 그래서 수식을 쓰기 전에 아래 규칙 파일을 따릅니다.

## 할 일

1. 먼저 `references/rules.md`를 읽습니다. 허용 명령, 대체표, 경로별 작성법이 모두 거기에 있습니다.
2. 사용자의 요청을 세 가지로 나눕니다.
   - **변환:** 교과서 문장이나 수식을 Amplify용으로 옮깁니다.
   - **검수:** 사용자가 쓴 수식에 대체표에 걸리는 명령이 있는지 봅니다.
   - **질문:** 특정 명령이 되는지 답합니다. 목록에 없으면 "확인하지 않았다"고 답합니다.
3. 수식은 백틱으로 감싸고, 한글 설명은 백틱 밖에 둡니다. 점 이름은 `\mathrm{}`으로 감쌉니다.
4. 결과는 `~~~` 코드 블록에 담아 복사하기 쉽게 줍니다.
5. 메모·수식 답변 칸에는 **붙여넣기**로 넣어야 한다고 안내합니다. 키보드로 치면 명령이 글자로 남습니다. CL `content` 문자열이면 백슬래시를 두 번 씁니다.

## 하지 않는 것

- 규칙 파일에 없는 명령이 그려진다고 단정하지 않습니다.
- "모든 LaTeX가 된다"거나 "전수 검사했다"고 말하지 않습니다.
- 학생 화면에서의 모양을 보증하지 않습니다(편집기 미리보기까지만 확인했습니다).
