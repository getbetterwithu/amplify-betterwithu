# Amplify 수식 입력 규칙

Amplify Classroom(Desmos)의 메모·수식 답변·CL에 들어갈 수학 수식을 쓸 때의 규칙입니다.

- **근거:** 2026-10-26, Amplify Classroom 편집기에서 계산기·메모·수식 답변·CL 네 경로를 직접 시험한 결과입니다. 같은 수식은 네 경로에서 결과가 같았습니다(38항 비교, 불일치 0).
- **범위:** 중학교 수학 교사가 쓰는 수식 중심입니다. **전수 검사가 아닙니다.** 이 문서에 없는 명령은 "확인하지 않음"입니다.
- **확인하지 못한 것:** 학생 계정 화면(편집기 미리보기만 확인), 다른 브라우저·모바일, 유니코드 기호 전체.

## 1. 기본 원칙

1. 수식은 앞뒤를 백틱(`` ` ``)으로 감쌉니다. 한글 설명은 백틱 밖에 둡니다.
2. 점 이름(A, B, C)은 `\mathrm{}`으로 감쌉니다. 쓰지 않으면 이탤릭이 됩니다. 변·변수 문자(a, b, x, y)는 `\mathrm`을 쓰지 않습니다.
3. 공백은 스페이스바가 아니라 `\ `(백슬래시 + 공백)입니다.
   - 복사해 쓴 기호(∽ ≡ ⫽ ∴ ∵ ⇒) 앞뒤: 반드시 넣습니다. 없으면 글자가 달라붙습니다.
   - 등호 `=`와 비례식 콜론 `:` 앞뒤: 넣으면 보기 좋습니다.
   - `+ − × ÷` 앞뒤: 넣지 않습니다. 자동으로 벌어집니다.
4. **지원하지 않는 명령은 글자로 남지 않고 칸이 통째로 비워집니다.** 그 줄의 수식 전체가 사라지므로 아래 대체표를 따릅니다.
5. 이 문서의 허용 목록에 없는 명령은 쓰지 않습니다. 꼭 필요하면 "Amplify에서 확인되지 않았다"고 알립니다.

## 2. 입력 경로별 작성법

| 경로 | 방법 |
|---|---|
| 메모, 수식 답변 | **붙여넣기로 넣습니다.** 키보드로 `\frac`을 한 글자씩 치면 명령이 되지 않고 백슬래시 글자로 남습니다. AI가 만든 결과도 복사해서 붙여넣게 안내합니다. |
| CL `content` 문자열 | 백슬래시를 **두 번** 씁니다. 예: `` content: "분수 `\\frac{1}{2}`" `` 한 번만 쓰면 `\n`으로 시작하는 명령(`\nsim` 등)이 줄바꿈으로 읽혀 깨집니다. |
| 계산기 수식 칸 | 같은 명령이 같게 그려집니다. |

## 3. 쓸 수 있는 명령 (시험에서 그려진 것)

### 기하
`\overline{\mathrm{AB}}` 선분 · `\underline{\mathrm{CD}}` 아랫줄 · `\overleftrightarrow{\mathrm{PQ}}` 직선 · `\overarc{\mathrm{AB}}` 호 · `\overrightarrow{}` `\overleftarrow{}` 반직선 · `\triangle\mathrm{ABC}` 삼각형 · `\angle\mathrm{A}` 각 · `\measuredangle` · `40\degree` 도 · `\perp` 수직 · `\parallelogram` 평행사변형 · `\bigcirc` 원 · `\square` · `\mathrm{ABC}` 꼭짓점 글자

### 식의 구조
`\frac{1}{2}` 분수 · `\sqrt{2}` 제곱근 · `\sqrt[3]{8}` 세제곱근 · `x^2` `x^{10}` 지수 · `a_1` `a_{12}` 아래첨자 · `\binom{n}{k}` · `\left(` `\right)` 큰 괄호 · `\sum_{k=1}^{n}k` · `\prod_{i=1}^{n}i` · `\int_0^1 x`

### 연산·관계
`\neq` `\leq` `\geq` · `\times` `\div` `\cdot` · `\pm` `\mp` · `\infty` · `\to` · `\approx` · `2:3` 비례식 콜론

### 서체·색
`\mathbf{}` 굵게 · `\textcolor{red}{}` 또는 `\textcolor{#2f6bd8}{}` 색(실제 색이 적용됨)

### 함수·그리스 문자
- 함수: `\sin` `\cos` `\tan` `\ln` `\log` `\max` `\min` `\gcd` `\exp` `\det` `\arg` 등은 곧은 글씨(연산자)로 그려집니다.
- 그리스 문자: `\alpha` `\gamma` `\delta` `\lambda` `\mu` `\pi` `\sigma` `\phi` `\omega` `\Delta` `\Sigma` `\Omega` 등 대부분.

### 복사해서 쓰는 유니코드 기호
`∽`(닮음) `≡`(합동) `⫽`(평행) `∴`(따라서) `≒`(근삿값) `∝`(비례) `⇔`(동치)는 계산기·메모에서 그려졌습니다. `∵`(왜냐하면) `⇒`(그러면)는 계산기 칸에서만 확인했고 다른 경로는 확인하지 않았습니다.

## 4. 대체표 (쓰면 안 되는 것 → 대신 쓸 것)

| 의도 | 쓰지 않음 (칸이 빔) | 대신 |
|---|---|---|
| 따라서 | `\therefore` | `∴` |
| 왜냐하면 | `\because` | `∵` |
| 합동 | `\equiv` | `≡` |
| 그러면 | `\Rightarrow` `\implies` | `⇒` |
| 동치 | `\Leftrightarrow` | `⇔` |
| 도 | `40^\circ` | `40\degree` |
| 세제곱근 | `\cbrt{8}` | `\sqrt[3]{8}` |
| 분수 | `1\over 2` | `\frac{1}{2}` |
| 조합 | `n\choose k` | `\binom{n}{k}` |
| 간격 | `\quad` | `\ ` |
| 말줄임 | `\ldots` `\cdots` | `…`를 백틱 밖에 |
| 글자 | `\text{AB}` | 한글·설명은 백틱 밖, 꼭짓점은 `\mathrm{AB}` |
| 그 밖 | `\underbrace` `\overbrace` `\mathbb` `\propto` `\bot` `\leftarrow` `\backsim` | 쓰지 않음 (`∝`은 유니코드로 가능) |

`\dfrac`와 `\cfrac`는 그려지지만 `\frac`과 같으므로 `\frac`만 씁니다.

## 5. 그려지지만 모양이 다른 것

| 입력 | 실제 모양 | 권장 |
|---|---|---|
| `\sim` | 물결 `~` | 닮음은 `∽` |
| `\parallel` | 곧은 평행 `∥` | 평행은 `⫽` |
| `\cong` | `≅` | 합동은 보통 `≡` |
| `\lim` `\lim_{x\to 0}` | 명령은 인식되지만 이탤릭 낱글자 l·i·m | 중학교 과정 밖이라 쓰지 않음 |
| `\deg` `\dim` `\hom` `\inf` `\ker` `\lg` `\sup` `\limsup` `\injlim` `\projlim` `\Pr`, `\operatorname{}` | 이탤릭 낱글자 | 곧은 글씨가 필요하면 쓰지 않음 |

`\vec` `\hat` `\dot` `\tilde`는 그림은 정상이고, 화면 낭독에만 `undefined`가 붙습니다.

## 6. AI가 답할 때

- 결과는 수식마다 복사하기 쉽게 `~~~` 코드 블록에 담아 줍니다(백틱이 들어 있어서 `~~~`를 씁니다).
- 대체표에 걸리는 명령을 썼다면 고쳐서 주고 한 줄로 알립니다.
- 목록에 없는 명령을 쓸 때는 확인되지 않았다고 말합니다. 그려진다고 단정하지 않습니다.
- 학생 화면, 다른 기기에서의 모양은 확인하지 않았다고 알립니다.
